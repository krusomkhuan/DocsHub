# Docs Hub — ศูนย์รวมงานจัดเก็บเอกสาร
ระบบเว็บแอปศูนย์รวมเอกสาร วิทยาลัยการอาชีพโพนทอง (PHP 8 + MySQLi + Bootstrap 5)

- **เวอร์ชัน:** 1.23.1
- **ผู้พัฒนาระบบ:** ครูสมควร สากำ ครูแผนกวิชาเทคโนโลยีธุรกิจดิจิทัล

> เปลี่ยนเลขเวอร์ชัน/ชื่อผู้พัฒนาได้ที่ `APP_VERSION`, `APP_DEVELOPER`, `APP_DEVELOPER_DEPT` ใน `includes/config.php`

## การติดตั้ง (XAMPP)
1. เปิด Apache และ MySQL ใน XAMPP Control Panel
2. ตรวจค่าฐานข้อมูลใน `includes/config.php` (ค่าเริ่มต้น root / ไม่มีรหัสผ่าน / ฐานข้อมูล `docshub`)
3. เปิด `http://localhost/docshub/` ระบบจะพาไปหน้า `install.php`
4. ตั้งชื่อผู้ใช้และรหัสผ่านผู้ดูแลระบบ แล้วกด "ติดตั้งระบบ"
5. ถ้าต้องการติดตั้งใหม่ ให้ลบไฟล์ `includes/installed.lock`

> ถ้าต้องการอัปโหลดไฟล์ใหญ่กว่า 40 MB ให้แก้ `upload_max_filesize` และ `post_max_size` ใน `C:\xampp\php\php.ini`

## ขอบเขตระบบ
| ส่วน | ไฟล์ |
|---|---|
| หน้าบ้าน: หน้าแรก ค้นหา หมวดเอกสาร | `index.php`, `documents.php`, `document.php`, `download.php` |
| สมาชิก: สมัคร/เข้าสู่ระบบ/ข้อมูลส่วนตัว | `register.php`, `login.php`, `profile.php` |
| สมาชิก: อัปโหลดเอกสาร เอกสารของฉัน | `upload.php`, `my-documents.php` |
| ออกเลขหนังสือราชการ (แยกตามแผนก) | `book-numbers.php`, `admin/book-numbers.php` |
| หลังบ้าน: แดชบอร์ด อนุมัติ/จัดการเอกสาร | `admin/index.php`, `admin/documents.php`, `admin/document-form.php` |
| หลังบ้าน: หมวดหมู่ แผนก สมาชิก ตั้งค่า บันทึกการใช้งาน | `admin/categories.php`, `admin/departments.php`, `admin/users.php`, `admin/settings.php`, `admin/logs.php` |

**การค้นหาเอกสาร:** ค้นทุกประเภทเอกสารพร้อมกัน (`document_filters()` ใน `includes/functions.php`) จากชื่อ เลขที่ ชื่อบุคคล รหัส/ชื่อวิชา รายละเอียด ปีการศึกษา ภาคเรียน ชื่อไฟล์ ชื่อประเภท หมวดหมู่ และแผนก (ชื่อ/รหัสย่อ) · หลายคำคั่นด้วยช่องว่าง = ทุกคำต้องพบ · หน้าแรกเลือกประเภทได้ข้างช่องค้นหา

ประเภทเอกสารเริ่มต้น: คำสั่งราชการ · เกียรติบัตร · แผนการสอน · โครงการสอน · หนังสือเรียน
- ผู้ดูแลระบบเพิ่ม/แก้ไข/ลบประเภทเอกสารได้ที่ หลังบ้าน → ประเภทเอกสาร (`admin/doc-types.php`) กำหนดไอคอน สี และช่องข้อมูลในฟอร์ม (วิชา, ภาคเรียน, ออกเลขคำสั่งอัตโนมัติ, ชื่อช่องบุคคล)
- ลบประเภทได้เฉพาะเมื่อยังไม่มีเอกสาร; หมวดหมู่ย่อยเพิ่มได้ที่ หลังบ้าน → หมวดหมู่เอกสาร
- การอัปเดตโครงสร้างฐานข้อมูลทำอัตโนมัติ (`includes/migrate.php`)

## จัดเก็บไฟล์ใน Google Drive
- หลังบ้าน → ตั้งค่าระบบ → **จัดเก็บไฟล์ใน Google Drive** (ค่าเริ่มต้น: เก็บในเครื่อง `uploads/docs`)
- ใช้ OAuth Client เดียวกับเข้าสู่ระบบด้วย Google + เปิด **Google Drive API** · ผู้ดูแลกด "เชื่อมต่อ Google Drive" → ใส่ **Folder ID** → "ทดสอบการเชื่อมต่อ" → เปิดสวิตช์
- ไฟล์ใหม่ (เอกสาร, ไฟล์/ภาพรายงานไปราชการ, หลักฐานบัญชี) ถูกส่งขึ้นโฟลเดอร์ใน Drive แล้วลบสำเนาในเครื่อง ฐานข้อมูลเก็บเป็น `gdrive:<fileId>`
- **โฟลเดอร์ตามประเภท** (ภายในโฟลเดอร์ DocsHub ตาม Folder ID สร้างให้อัตโนมัติ): คำสั่ง → `uploads/commands` · แผนการสอน/โครงการสอน → `uploads/plans` · หนังสือเรียน → `uploads/books` · เกียรติบัตร → `uploads/certs` · ใบเสร็จ → `uploads/receipt` (เปลี่ยนได้ในหน้าตั้งค่า) · ภาพและไฟล์รายงานไปราชการ → `uploads/trips/reports` · อื่น ๆ ทั้งหมด → `uploads/docs` · กำหนดใน `STORAGE_DOC_FOLDERS` (`includes/gdrive.php`)
- ระบบสร้างโฟลเดอร์ย่อยที่ยังไม่มีให้เอง (เมื่ออัปโหลดไฟล์แรกหรือกด "ทดสอบการเชื่อมต่อ") โฟลเดอร์ที่มีอยู่แล้วไม่สร้างซ้ำ · ย้ายไฟล์เดิมจากเซิร์ฟเวอร์ขึ้น Drive ใช้ `tools/move-to-drive.php` (ไม่มีปุ่มในหน้าตั้งค่า)
- ไฟล์ที่อยู่ใน Drive แล้ว จัดเข้าโฟลเดอร์ตามประเภทได้ด้วยปุ่ม "จัดไฟล์ใน Drive เข้าโฟลเดอร์ตามประเภท" (หรือ `tools/move-to-drive.php`)
- **ภาพโปรไฟล์ (avatar) เก็บในเครื่องที่ `uploads/docs/avatars` เสมอ** ไม่ส่งขึ้น Drive (ภาพที่เคยถูกย้ายขึ้น Drive ดึงกลับได้ด้วยปุ่มในหน้าตั้งค่า หรือ `tools/move-to-drive.php`)
- ไฟล์ใน Drive เป็นส่วนตัว ดาวน์โหลดผ่านระบบ (ตรวจสิทธิ์) · ลบในระบบ = ย้ายไปถังขยะ Drive · **เปิดสวิตช์ = เก็บใน Drive เท่านั้น**: ส่งขึ้น Drive ไม่สำเร็จ ผู้ใช้จะได้รับแจ้งให้ลองใหม่ ลบไฟล์ชั่วคราว และบันทึก `gdrive_error` (ไม่เก็บสำรองในเครื่อง) · ยกเลิกการเชื่อมต่อระหว่างเปิดสวิตช์ = อัปโหลดไม่ได้จนกว่าจะเชื่อมใหม่
- ไฟล์เดิมในเครื่องใช้งานได้ต่อ (เก็บได้ทั้งสองที่พร้อมกัน) · การสำรองแบบเต็มไม่รวมไฟล์ใน Drive · ไฟล์สำรองมี refresh token ของ Drive ควรเก็บในที่ปลอดภัย
- ไฟล์: `includes/gdrive.php` (Drive API + ชั้นจัดเก็บไฟล์), `gdrive-connect.php`

## เข้าสู่ระบบด้วย Google
- เปิด/ปิดที่ หลังบ้าน → ตั้งค่าระบบ → **เข้าสู่ระบบด้วย Google** (ค่าเริ่มต้น: ปิด)
- ต้องสร้าง OAuth Client ID (Web application) ที่ Google Cloud Console และใส่ Authorized redirect URI ตามที่หน้าตั้งค่าแสดง (`.../google-callback.php`) — Google รับเฉพาะ https (ยกเว้น http://localhost)
- จำกัดเฉพาะอีเมลโดเมนวิทยาลัยได้ (เช่น pticec.ac.th) · เลือกได้ว่าจะให้ผู้ที่ยังไม่มีบัญชีสมัครด้วย Google หรือไม่ (ต้องเลือกแผนก + ยอมรับ PDPA, อนุมัติตามการตั้งค่าอนุมัติสมาชิก)
- ความปลอดภัย: Authorization Code + PKCE, state ใช้ครั้งเดียว, nonce, ตรวจ iss/aud/exp ของ ID token, รับเฉพาะอีเมลที่ยืนยันแล้ว, ไม่เชื่อมบัญชีเดิมจากอีเมลอัตโนมัติ (ผู้ใช้เดิมกด "เชื่อมบัญชี Google" ที่หน้าข้อมูลส่วนตัว)
- ไฟล์: `google-login.php`, `google-callback.php`, `google-register.php`, `includes/google_auth.php`

## คลังรูปภาพ
- เมนู **คลังรูปภาพ** (`photo-albums.php`) ระบบสืบค้นลิงก์อัลบั้มภาพกิจกรรม (Google Photos, Drive, Facebook, YouTube ฯลฯ) ทุกคนค้นหาได้ นับจำนวนครั้งที่เปิด
- สมาชิกส่งลิงก์ (`photo-album-form.php`) → รอเจ้าหน้าที่อนุมัติ · ตรวจลิงก์ซ้ำและรับเฉพาะ http/https
- หลังบ้าน → คลังรูปภาพ: อนุมัติ/ไม่อนุมัติพร้อมเหตุผล แก้ไข ลบ
- **นำเข้าข้อมูลเดิม (เฉพาะผู้ดูแลระบบ):** อัปโหลด .xlsx / .csv / .tsv / .txt (ไม่เกิน 10 MB, 5,000 แถว) หรือวางรายการ → ตรวจตัวอย่าง → ยืนยัน
  - หาคอลัมน์ชื่ออัลบั้ม/ลิงก์/วันที่/ปีการศึกษาจากหัวตารางอัตโนมัติ รองรับลิงก์แบบ hyperlink และสูตร HYPERLINK ใน Excel วันที่แบบเลขของ Excel และ พ.ศ.
  - CSV ภาษาไทยทั้ง UTF-8 และ Windows-874 · ข้ามลิงก์ที่มีในคลังแล้วและลิงก์ซ้ำในไฟล์ · มีไฟล์ตัวอย่างให้ดาวน์โหลด

## รายงานการไปราชการ
- เมนู **รายงานไปราชการ** (`trip-reports.php`) และในหน้าเอกสารคำสั่งไปราชการจะมีปุ่ม **เขียนรายงาน**
- รายงานผูกกับคำสั่งไปราชการ มีหัวข้อ: เรื่อง สถานที่ วันที่ไป-กลับ ผู้ไปราชการ วัตถุประสงค์ ผลการไปราชการ ประโยชน์ที่ได้รับ ข้อเสนอแนะ ค่าใช้จ่าย และไฟล์รายงานแนบ
- **แนบภาพประกอบ** ได้สูงสุด 30 ภาพต่อรายงาน (JPG/PNG/WEBP) พร้อมคำบรรยายภาพ ระบบย่อภาพให้อัตโนมัติ (ด้านยาว 1600px) และหมุนภาพจากมือถือให้ถูกทิศ
- ดูภาพแบบเลื่อนดูทีละภาพ และ **พิมพ์ / บันทึก PDF** เป็นแบบรายงาน A4 พร้อมช่องลงชื่อผู้รายงาน
- หมวดหมู่ที่ใช้รายงานนี้ได้ ตั้งที่ หลังบ้าน → หมวดหมู่เอกสาร → "เปิดใช้รายงานการไปราชการ" (ค่าเริ่มต้น: คำสั่งไปราชการ)
- ภาพเก็บที่ `uploads/docs/trips/` และถูกรวมในไฟล์สำรองแบบเต็มด้วย

## ตั้งค่าเพิ่มเติม (v1.4)
- **URL ของระบบ** (หลังบ้าน → ตั้งค่าระบบ): ใช้สร้างลิงก์เต็มของปุ่ม "คัดลอกลิงก์" ในหน้าเอกสาร/รายงานไปราชการ และพิมพ์ท้ายรายงาน เว้นว่าง = ใช้ที่อยู่ที่เปิดอยู่
- **URL เว็บไซต์วิทยาลัย**: แสดงเป็นลิงก์ชื่อวิทยาลัยที่ท้ายเว็บ
- **ภาพโปรไฟล์**: สมาชิกอัปโหลดได้ที่หน้า ข้อมูลส่วนตัว (ครอปสี่เหลี่ยมจัตุรัส 320px อัตโนมัติ) ผู้ดูแลเปลี่ยน/ลบให้ได้ที่หน้า สมาชิก
- **ปีการศึกษา** (หลังบ้าน → ปีการศึกษา): ผู้ดูแลเพิ่ม/แก้ไข/ลบ และกำหนดปีปัจจุบัน ซึ่งจะถูกเลือกไว้ให้ในฟอร์มอัปโหลดและใช้เป็นตัวกรองเอกสาร

## บัญชีรายรับ-รายจ่ายแผนกวิชา
- เมนู **บัญชีแผนก** (`ledger.php`) เป็นส่วนแยกในแถบเมนู (dropdown: ภาพรวม · บันทึกรายรับ/รายจ่าย · รายการรายรับ/รายจ่าย · ส่งออก CSV · หมวดและการตั้งค่า) และมีแถบเมนูย่อยในทุกหน้าบัญชี (`includes/ledger_nav.php`) · แสดงเฉพาะผู้ที่สังกัดแผนกวิชา
- **สิทธิ์:** ดูและบันทึกได้เฉพาะครูที่บัญชีผู้ใช้ระบุแผนกนั้น กำหนดว่าใครอยู่แผนกไหนได้ที่ หลังบ้าน → สมาชิก
- **ครูแผนกอื่น เจ้าหน้าที่ และผู้ดูแลระบบ** ที่ไม่ได้สังกัดแผนกนั้น **ไม่เห็นบัญชี** (ระบบใช้แผนกจากบัญชีผู้ใช้เท่านั้น ไม่รับค่าแผนกจาก URL)
- บันทึกรายรับ/รายจ่าย พร้อมหมวด เลขที่ใบเสร็จ ผู้รับ/ผู้จ่ายเงิน และแนบหลักฐาน (ใบเสร็จ/ภาพถ่าย/PDF)
- สรุปตาม **ปีงบประมาณ** (1 ต.ค. – 30 ก.ย.): ยอดยกมา รายรับ รายจ่าย คงเหลือ สรุปรายเดือนพร้อมยอดสะสม และแยกตามหมวด
- ค้นหา/กรอง ส่งออก CSV พิมพ์รายงาน และแชร์สรุปยอด (ยกมา/รายรับ/รายจ่าย/คงเหลือ) พร้อมลิงก์ไป LINE ได้ (`line.me/R/share`)
- ครูในแผนกแก้ไขรายการได้ทุกคน (ระบบเก็บชื่อผู้แก้ไขล่าสุด) แต่ลบได้เฉพาะรายการที่ตนบันทึก
- **ผู้รับผิดชอบบัญชี:** ผู้ดูแลระบบเป็นผู้แต่งตั้งที่ หลังบ้าน → ผู้รับผิดชอบบัญชีแผนก (แผนกละกี่คนก็ได้ ต้องสังกัดแผนกนั้น) ผู้รับผิดชอบบัญชีบันทึก/แก้ไข/ลบได้ทุกรายการ และจัดการหมวด · ครูทุกคนในแผนกบันทึกและแก้ไขรายการได้ทุกรายการ (แก้รายการเก่าที่บันทึกผิดได้ ระบบเก็บผู้แก้ไขล่าสุด) ลบได้เฉพาะรายการของตน แผนกที่ยังไม่มีผู้รับผิดชอบบัญชี ครูทุกคนในแผนกใช้งานได้
- หมวดรายรับ-รายจ่ายแต่ละแผนกแยกกัน แก้ไขได้ที่ปุ่ม <i>หมวด</i> ในหน้าบัญชี
- บันทึกการใช้งานของระบบ เก็บเพียงเลขรายการ ไม่เก็บจำนวนเงินหรือรายละเอียด

## PDPA (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562)
- **นโยบายคุ้มครองข้อมูลส่วนบุคคล** (`privacy.php`) ลิงก์อยู่ท้ายทุกหน้า มีแม่แบบเริ่มต้นที่เขียนตามข้อมูลที่ระบบนี้เก็บจริง — **ควรให้ผู้รับผิดชอบด้านกฎหมาย/DPO ของวิทยาลัยตรวจทานก่อนใช้งานจริง**
- **ความยินยอม:** ติ๊กยอมรับตอนสมัครสมาชิก และเมื่อเผยแพร่นโยบายฉบับใหม่ ผู้ใช้ทุกคนต้องยอมรับใหม่ก่อนใช้งานต่อ ระบบบันทึกเวลา ฉบับ และ IP ของทุกการยอมรับ/ถอน
- **ข้อมูลส่วนบุคคลของฉัน** (`my-data.php`): ดูข้อมูลที่ระบบเก็บ ดาวน์โหลดเป็น JSON ยื่นคำร้องใช้สิทธิ์ (เข้าถึง แก้ไข ลบ คัดค้าน ระงับ ขอรับข้อมูล) ติดตามสถานะ และถอนความยินยอม
- **หลังบ้าน → PDPA:** จัดการคำร้อง (ครบกำหนด 30 วัน แจ้งเตือนเมื่อเกิน) ลบข้อมูลส่วนบุคคลของบัญชีแบบ anonymize แก้ไข/เผยแพร่นโยบายฉบับใหม่ ตั้งข้อมูลเจ้าหน้าที่ DPO ระยะเวลาเก็บประวัติการใช้งาน (ลบอัตโนมัติ) และดูบันทึกความยินยอม
- แจ้งการใช้คุกกี้ (มีเฉพาะคุกกี้ที่จำเป็น)

## คู่มือการใช้งานและการตรวจสอบระบบ
- **คู่มือการใช้งาน** (`manual.php`): ไอคอน <i>?</i> บนแถบเมนู และลิงก์ในหลังบ้าน แบ่งตามหัวข้อและบทบาทผู้ใช้ พิมพ์/บันทึกเป็น PDF ได้
- **ตรวจสอบระบบ** (หลังบ้าน → ตรวจสอบระบบ, `admin/system-check.php`): ตรวจ PHP/ส่วนขยาย/php.ini, ฐานข้อมูลและเวอร์ชันโครงสร้าง, โฟลเดอร์/พื้นที่ดิสก์/การสำรองข้อมูล, ไฟล์ป้องกันและการเข้าถึงตรงจากเว็บ, สคริปต์แปลกปลอมในโฟลเดอร์อัปโหลด, ไฟล์ข้อมูลที่หายไป และความถูกต้องของไฟล์โปรแกรม (SHA-256 เทียบกับค่าอ้างอิงใน `database/integrity.json`)
- ตรวจจากบรรทัดคำสั่ง: `C:\xampp\php\php.exe C:\xampp\htdocs\docshub\tools\check.php` (exit code 1 เมื่อมีรายการไม่ผ่าน)
- หลังอัปเดตไฟล์ระบบทุกครั้ง ให้กด **บันทึกค่าอ้างอิง** ในหน้าตรวจสอบระบบ

## สิทธิ์ผู้ใช้
- **สมาชิก** อัปโหลดเอกสาร (รออนุมัติ) ดูเอกสารภายใน ออกเลขหนังสือของแผนกตนเอง
- **เจ้าหน้าที่** เข้าหลังบ้าน อนุมัติ/แก้ไข/ลบเอกสารทุกฉบับ ออกเลขและยกเลิกเลขได้ทุกแผนก ส่งออก CSV
- **ผู้ดูแลระบบ** ทุกอย่าง รวมถึงสมาชิก แผนก ตั้งค่า และบันทึกการใช้งาน

## เลขหนังสือราชการ
- เลขรันใหม่ทุกปี พ.ศ. แยกตามแผนก และประเภท (หนังสือส่ง / รับ / บันทึกข้อความ / คำสั่ง)
- รูปแบบตั้งได้ที่ ตั้งค่าระบบ เช่น `{code} {no}/{year}` → `ชฟ 001/2569`
- ใช้ transaction + row lock ป้องกันเลขซ้ำเมื่อมีคนขอพร้อมกัน; เลขที่ยกเลิกจะไม่ถูกนำกลับมาใช้
- อัปโหลดคำสั่งราชการแล้วติ๊ก "ออกเลขคำสั่งอัตโนมัติ" ได้
- **กำหนดเลขเริ่มต้น** (เจ้าหน้าที่/ผู้ดูแลระบบ) แยกตามแผนก ประเภท และปี พ.ศ. ในหน้าออกเลขหนังสือ เลขถัดไป = ค่าที่มากกว่าระหว่างเลขเริ่มต้นกับเลขล่าสุด + 1

## ความปลอดภัย
- mysqli prepared statements ทุกคำสั่ง, password_hash, CSRF token ทุกฟอร์ม, จำกัดการเดารหัสผ่าน
- ไฟล์เก็บใน `uploads/docs` ที่ปิดการเข้าถึงตรง (`.htaccess`) ดาวน์โหลดผ่าน `download.php` ที่ตรวจสิทธิ์เท่านั้น
- จำกัดนามสกุลไฟล์ (`ALLOWED_EXT` ใน `includes/config.php`) และสุ่มชื่อไฟล์ที่จัดเก็บ

## สำรองและกู้คืนข้อมูล
หลังบ้าน → **สำรอง / กู้คืนข้อมูล** (`admin/backup.php`, ผู้ดูแลระบบเท่านั้น)
- **สำรองแบบเต็ม** (ฐานข้อมูล + ไฟล์เอกสาร) หรือ **เฉพาะฐานข้อมูล** ได้เป็นไฟล์ `.zip` ไฟล์เดียว เก็บใน `backups/` (ปิดการเข้าถึงจากเว็บ)
- ดาวน์โหลดไฟล์สำรองไปเก็บนอกเครื่องเซิร์ฟเวอร์ได้ (แนะนำ: แฟลชไดรฟ์ / Google Drive)
- **ส่งสำเนาไป Google Drive อัตโนมัติ** ที่ `DocsHub/uploads/backups` ทุกครั้งที่สำรอง (สำรองด้วยตนเอง / อัตโนมัติ / Task Scheduler / ก่อนกู้คืน) เมื่อเชื่อมต่อ Drive ไว้ · ยังเก็บสำเนาในเซิร์ฟเวอร์เพื่อใช้กู้คืน · จำนวนไฟล์ใน Drive ลดตามการตั้งค่า "เก็บไฟล์สำรองล่าสุด" · ส่งไม่สำเร็จ การสำรองยังสำเร็จและแจ้งเตือน
- **กู้คืน** จากไฟล์ในรายการ หรืออัปโหลดไฟล์ .zip ต้องยืนยันรหัสผ่าน และระบบจะสำรองสถานะปัจจุบัน (`-prerestore`) ให้ก่อนทุกครั้ง
- **สำรองอัตโนมัติ** ทุก N วัน (ทำงานเมื่อเปิดแดชบอร์ดหลังบ้าน) และกำหนดจำนวนไฟล์ที่เก็บไว้ได้

### ตั้งเวลาสำรองด้วย Windows Task Scheduler
สร้าง Task ใหม่ → Action: Start a program → เลือกไฟล์ `tools\backup-task.bat` (สำรองแบบเต็ม บันทึกผลที่ `backups\backup-task.log`)

### เมื่อเข้าเว็บไม่ได้ (ฐานข้อมูลเสีย/ถูกลบ)
เปิด MySQL แล้วรันใน Command Prompt:
```
C:\xampp\php\php.exe C:\xampp\htdocs\docshub\tools\restore.php
C:\xampp\php\php.exe C:\xampp\htdocs\docshub\tools\restore.php ชื่อไฟล์สำรอง.zip
```
คำสั่งแรกแสดงรายการไฟล์สำรอง คำสั่งที่สองกู้คืน (สร้างฐานข้อมูลใหม่ให้ถ้าถูกลบไป) ตัวเลือก `--db-only`, `--files-only`, `--yes`

### ย้ายเครื่อง / ติดตั้งใหม่
คัดลอกโฟลเดอร์ระบบ → `install.php` → เข้าหลังบ้าน → กู้คืนจากไฟล์ .zip (หรือใช้ `tools\restore.php` ได้เลยโดยไม่ต้องติดตั้ง)
